# Experimento FPUT

Conjunto de programas en **Fortran 95** y **Python** para la simulación del sistema Fermi–Pasta–Ulam–Tsingou (FPUT), asociados al Trabajo de Fin de Grado (TFG):

- **Título:** El experimento de Fermi-Pasta-Ulam-Tsingou  
- **Autor:** Alejandro Mata Ali  
- **Tutor:** José Manuel Sánchez de Santos  
- **Institución:** Universidade de Santiago de Compostela (USC)

## Contenido

| Carpeta / archivo | Descripción |
| --- | --- |
| `Códigos Fortran/` | Simulaciones FPUT (α/β), superrecurrencia, solitones, espacio de fases |
| `Graficadoras/` | Scripts Python para graficar y postprocesar resultados |
| `El experimento de Fermi-Pasta-Ulam-Tsingou.pdf` | Memoria del TFG |

Instrucciones básicas de los programas Fortran: ver `Códigos Fortran/Instrucciones.txt`.
